Same chance. Separate boards.
Slide tiles with arrow keys, WASD, the direction buttons, or a swipe. Equal tiles merge once per move. A merge adds the new tile’s value to your score.
You and the opponent start identically. Every successful move advances both active boards once and adds the same tile value using a shared, hidden position priority. Different empty cells can produce different spawn locations.
The higher final merge score wins. Reaching 2048 does not end the match. A blocked board freezes; the other continues. Each board is capped at 2,048 successful moves. Equal final scores are a draw. There is no undo or speed bonus.
Live JEV judges structured candidate rubrics; JavaScript handles exact rules and lookahead. Difficulty changes the evidence and search budget—not luck. Its strength has not been established by a live-provider benchmark.
Ranked play needs Discord and the real JEV service. Use /2048 in an approved Discord channel for channel/server attribution. A local heuristic is always unranked and clearly labeled.

Your data and the evidence.
Required gameplay records include boards, actions, spawns, candidate features, JEV requests and answers, usage, and event hashes. Secrets and future seeds are never included in active-match exports.
Discord login stores your user ID, display name, and avatar reference. No email scope is requested. Community context proves a recent launch, not perpetual channel access.
Optional browser analytics records game input timing, network timing, visibility, and frame gaps. These are labeled untrusted and are never used to score a match. It is off by default and can be turned off in Analytics.
Exports are private to the match owner. World leaderboards show verified scores and display names, not community identifiers. The host controls retention and deletion; the package includes a maintenance tool. There are no third-party tracking services.
